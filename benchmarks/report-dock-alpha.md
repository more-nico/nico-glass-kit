# Dock 动态宽度黑块修复验证

验证日期：2026-10-22。玻璃库基于 `4bf80bf` 加本次补丁；Nico 宿主基于 `cbe48faf938ff52ec2bf561f489d359cd477351a`。验证使用本地库构建，补丁收录于 0.3.3，版本说明见 `CHANGELOG.md`。

## 修复内容

`lensChannelMatrix` 的三个 RGB 提取矩阵将 alpha 行从 `0 0 0 0 1` 改为 `0 0 0 1 0`，保留位移输入的透明度，避免将透明采样转换为不透明黑色。这对应 [W3C 的颜色矩阵运算](https://www.w3.org/TR/filter-effects-1/#feColorMatrixElement)。RGB 提取、位移强度和两次 screen 混合保持原样。

修正原单元测试中把常数 alpha 1 误当作透传的断言，改为对三个通道分别输入 alpha `0`、`0.25`、`0.5`、`1`，计算并验证完整 RGBA 输出。

新增浏览器测试从实际 registry 克隆滤镜图，在透明画布及蓝色背景上验证完全透明、半透明和不透明源。关闭色散及色散 `0.1` 两条路径都覆盖。三路半透明输入经过 screen 后，alpha 按现有 source-over 合成为 `0.875`，而非强制成为 `1`；测试同时检查 RGB 和背景衔接，允许最多 2 个色阶的光栅化误差。合成预期依据 [W3C alpha 合成](https://www.w3.org/TR/compositing-1/#porterduffcompositingoperators_srcover)及 [screen 定义](https://www.w3.org/TR/compositing-1/#blendingseparable)。

另覆盖 300ms 宽度过渡中的连续反向切换，分别使用弹性 `0`、`0.2`，验证结束后贴图尺寸、三个矩阵的透明度、滤镜引用及卸载清理。

## 确定性回归

```sh
npm test
npm run typecheck
npm run build
npm run test:browser
```

结果：217 个单元测试、15 个浏览器测试全部通过；类型检查和 ESM/CJS 构建通过。修改生产代码前，新单元测试失败；浏览器透明源实验在色散 `0.1` 下读到 `[0, 0, 0, 255]`。修改后同一位置为 `[0, 0, 0, 0]`，无色散路径两次均通过。

## 硬件加速宿主验证

有窗口的 Edge Canary `158.0.4354.0`，macOS `27.0.1`（`26A434`），Apple M4 / ANGLE Metal。CDP 确认 `gpu_compositing: enabled`、`rasterization: enabled`。初始视口 `1440 × 900`，DPR 2，`zh-CN`，未开启减少动态效果。使用默认《睡莲》壁纸、high 质量、auto 明暗及宿主默认材质。

网页预览通过临时 Vite alias 引入本地 `dist`；真实 MV3 扩展使用同一 alias 构建，在独立临时浏览器 profile 中通过 `Extensions.loadUnpacked` 加载。宿主源码及依赖清单均未修改。

六个页面名依次为：首页、工作与效率工具、设计、阅读收藏和稍后处理、开发工具、生活。快速滑动按报告在初始 Dock 左右边缘往返，`mouse.move` 每方向 5 步，网页 16 轮、扩展 12 轮。缩放场景连续 32 次改变视口宽度（360–1440px），同时移动指针以触发标签动画。最后移出指针，等待 600ms。

两组都运行本次库构建；旧行为对照仅将三个矩阵恢复为常数 alpha 1，并对后来生成的滤镜继续应用这一修改。CDP PNG 截帧检测 Dock 上缘内部条带（横向去掉两端各 27px，纵向 top+3 至 top+12px），RGB 三分量均小于 25 的像素超过 10 个即计为黑块帧。另检查保存的截图。

| 场景 | 网页黑块帧 / 总帧 | MV3 扩展黑块帧 / 总帧 |
| --- | ---: | ---: |
| 恢复旧矩阵，快速滑动 | 11 / 76 | 44 / 58 |
| 修复后，快速滑动，弹性 0.2 | 0 / 78 | 0 / 58 |
| 修复后，快速滑动，弹性 0 | 0 / 73 | 0 / 58 |
| 修复后，快速滑动，色散 0 | 0 / 76 | 0 / 58 |
| 修复后，窗口缩放，弹性 0.2 | 0 / 94 | 0 / 91 |
| 修复后，窗口缩放，弹性 0 | 0 / 100 | 0 / 92 |

所有场景结束后 Dock 与贴图均恢复为 306px，逐帧 DOM 采样未发现失效的滤镜引用，未记录到页面异常。每行均为独立单次采样；阈值仅用于当前壁纸的上缘黑条，不能将这些数字解读为发生率或其他平台的保证。

本地原始数据、截图、验证脚本、临时 alias 配置和扩展构建保存在 `benchmarks/results/dock-alpha/`（gitignored）。被测 ESM 文件的 SHA-256 为 `2efad3cdfb9e0a01a0eba5ea41aff7d4f36f62ff319faab7ceaff51585d1a428`。

## 尺寸同步的范围

本补丁保留现有 100ms 尾沿尺寸防抖。动态过程中仍观察到贴图尺寸滞后，修复后这些采样未再出现上缘黑条。尺寸同步与折射对齐仍可单独改进；本次没有改成每次 resize 都生成 PNG，也没有以关闭弹性或色散替代修复。
