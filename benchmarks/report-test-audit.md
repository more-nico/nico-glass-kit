# 测试精简与 0.3.4 发布验证

日期：2026-10-22（Asia/Shanghai）。检查范围包括 `src` 下全部测试、浏览器回归、性能实验、证据打包脚本和 npm 生命周期。

## 结论与改动

核心断言没有大面积同义重复。重复主要集中在初始化、清理和历史数据处理，不能通过删除独立回归来缩减测试数量。

| 位置 | 精简方式 | 保留的覆盖 |
| --- | --- | --- |
| `probeScheduling.test.ts` | 四套模拟浏览器/时钟合为一个环境，统一恢复全局变量和计时器 | 公平调度、节流、分帧续算、隐藏/卸载取消、首点成本 |
| 浏览器回归 | 共用页面初始化、类型、异常和卸载检查 | 每个页面用例都验证无页面异常、无残留滤镜/ResizeObserver |
| 尺寸检查 | 12 次相邻参数遍历改为三组奇数尺寸、普通圆角和半径钳制场景；两个仅检查停止后尺寸的用例改为三个连续宽高动画场景 | Medium/High 共享滤镜、High 私有滤镜、当前帧尺寸、所有权隔离、亮度与滤镜身份连续性 |
| 三份证据打包脚本 | 抽取共用 PNG 拼图/统计、SHA-256 和文件清单 | 各轮独立的构建 hash 防护、路径、报告元数据和原始证据 |
| 旧 `profile.mjs` | 删除重复 CPU 分析入口及写死旧 `baseline/pilot` 目录的截图比较 | CPU 诊断由 `probe-profile.mjs` 保留，截图比较由 `compare.mjs` 保留 |
| 发布流程 | 新增 `test:release`；验证后打包、发布同一 tarball，跳过重复生命周期检查 | 类型、单元、浏览器、库与 playground 构建 |

48 组矩形像素和 6 组字形像素/SDF/ring 冻结基线不是冗余：它们覆盖不同几何、像素编码和优化兼容性。单位测试与浏览器像素测试分别检查算法和实际渲染，也予以保留。

约 37 MB 的 `evidence*` 目录是历史报告对应的截图、数据与冻结构建，不会被测试命令执行，也不会进入 npm 包。其 81 个文件的校验和全部匹配；共用工具重建的第一轮对比 PNG 与归档字节相同，全部像素统计相同，并拒绝越界裁剪。

## 本次验证

- 类型检查通过；20 个单元测试文件、219 个用例通过。
- 16 个浏览器回归通过，完整一次耗时 14.5 秒（Edge Canary，headless）；不作为 GPU 性能数据。
- 三种滤镜模式的连续尺寸采样均要求宽、高与贴图误差为 0；私有滤镜 ID 不变，共享滤镜不改变其他所有者。
- 库 ESM/CJS/声明构建与 playground 生产构建通过。
- 所有 benchmark JavaScript 脚本语法检查通过；未重跑历史性能实验、重新冻结期望值或改写历史证据。

初次验证发现 DPR 用例只改 CDP 倍率时，headless Edge 没有发送 resize/resolution 事件。用例现在改变 1px 视口以触发原生 resize，保持组件 CSS 尺寸不变，继续断言 DPR 和 PNG 已更新。该修正通过单独复测及最终浏览器回归。

可复跑入口：`npm run test:release`。已有 Chromium 可通过 `BENCH_BROWSER_PATH` 指定。
